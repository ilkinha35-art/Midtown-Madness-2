# Midtown Clone 🚗💨

Um projeto inspirado no clássico **Midtown Madness 2**, recriado como um jogo open-source para fins educacionais e de diversão.  
Este projeto **não contém** o jogo original da Microsoft, apenas um remake feito pela comunidade.

---

## 🎯 Objetivo
Criar um jogo de corrida em mundo aberto com:
- Carros controláveis com física arcade
- Cidade explorável com ruas, cruzamentos e tráfego
- Corridas contra o tempo e contra adversários
- Sistema de tráfego com veículos NPC

---

## 🛠️ Tecnologias
- **Engine:** Unity / Godot / Unreal (escolha a que preferir)
- **Linguagem:** C# (Unity), GDScript (Godot) ou C++ (Unreal)
- **Controle de versão:** Git + GitHub
